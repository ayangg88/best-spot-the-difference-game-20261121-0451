Twin Lanterns — a spot-the-difference game: three hand-drawn scenes (a night lantern market, a harbour at dusk, a secret garden), seven differences hidden in each, gold rings and checkmarks on every find, a hint that costs ten seconds, combo scoring, and clocks that get shorter as the scenes get harder. Mouse or keyboard, no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play.
